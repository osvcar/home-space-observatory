WORKFLOW
1. RAW photos -> archive/missions/missionXXX/raw/
2. Processed files -> archive/missions/missionXXX/processed/
3. Final full-resolution files -> archive/missions/missionXXX/final/
4. Website versions (preview / medium / thumb) -> repo/missions/missionXXX/img/
5. metadata.json -> repo/missions/missionXXX/data/

RULES
- RAW files never go to GitHub
- Heavy files (>50 MB) never go to normal GitHub
- GitHub only stores website-ready files
- Full-resolution download files should be hosted externally when needed
